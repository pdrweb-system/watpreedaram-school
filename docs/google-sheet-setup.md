# วิธีตั้งค่า Google Sheet เพื่อแก้ไขข้อมูลเว็บไซต์เอง

คู่มือนี้สำหรับผู้ดูแลเว็บไซต์ (ไม่ต้องเขียนโค้ดเป็น) ใช้ครั้งเดียวตอนตั้งค่า
หลังจากนั้นแก้ไขข้อมูล "บุคลากร", "ฝ่ายงาน" และ "ติดต่อเรา" ได้จากการพิมพ์ในตาราง Google Sheet
เหมือนแก้ Excel ธรรมดา เว็บไซต์จะดึงข้อมูลไปแสดงให้อัตโนมัติ ไม่ต้องแก้โค้ดหรือขอให้ใครช่วยแก้เว็บอีก

ข่าวสารยังคงดึงจากเพจ Facebook ของโรงเรียนโดยตรงเหมือนเดิม ไม่เกี่ยวกับคู่มือนี้

## ขั้นตอนที่ 1 — สร้าง Google Sheet

1. เข้า [sheets.google.com](https://sheets.google.com) แล้วสร้างสเปรดชีตใหม่ ตั้งชื่อว่า เช่น
   "ข้อมูลเว็บไซต์โรงเรียนวัดปรีดาราม"
2. ลบแท็บ "Sheet1" เดิมทิ้ง แล้วสร้างแท็บใหม่ 4 แท็บ **ตั้งชื่อแท็บให้ตรงเป๊ะ** ตามนี้:
   - `ผู้บริหาร`
   - `กลุ่มสาระ`
   - `ฝ่ายงาน`
   - `ติดต่อ`

## ขั้นตอนที่ 2 — ใส่หัวตารางและข้อมูลในแต่ละแท็บ

หัวตาราง (แถวที่ 1) ต้องสะกดตรงตามนี้ (เป็นภาษาอังกฤษ) ส่วนข้อมูลด้านล่างใส่เป็นภาษาไทยได้ตามปกติ

### แท็บ `ผู้บริหาร`
มีกี่แถวก็ได้ (เช่น ผอ. + รอง ผอ.)

| Initial | Role | Name | Note |
|---|---|---|---|
| ผอ | ผู้อำนวยการโรงเรียน | (ชื่อ-นามสกุลจริง) | (ข้อความสั้น ๆ แนะนำผู้บริหาร) |

### แท็บ `กลุ่มสาระ`
1 แถวต่อครู 1 คน — ครูในกลุ่มสาระเดียวกันให้ใส่ชื่อกลุ่มในคอลัมน์ `Group` เหมือนกัน
เว็บจะรวมครูที่มี `Group` เดียวกันไว้ในแถบเดียวกันเอง

| Group | Initial | Name | Subject |
|---|---|---|---|
| กลุ่มสาระการเรียนรู้ภาษาไทย | ค1 | (ชื่อครู) | ป.1-3 |
| กลุ่มสาระการเรียนรู้คณิตศาสตร์ | ค2 | (ชื่อครู) | ป.4-6 |

### แท็บ `ฝ่ายงาน`
1 แถวต่อ 1 ลิงก์ — ฝ่ายไหนมีหลายระบบ (เช่น ฝ่ายบุคคล) ให้ใส่หลายแถวโดยใช้ `Name` และ `Description` ซ้ำกัน
เว็บจะรวมลิงก์ของฝ่ายเดียวกันไว้ในการ์ดเดียว

| Name | Description | LinkLabel | LinkURL |
|---|---|---|---|
| ฝ่ายบริหารงานวิชาการ | ดูแลหลักสูตร การจัดการเรียนการสอน การวัดและประเมินผล | ระบบประเมิน SDQ | https://... |
| ฝ่ายบริหารงานบุคคล | ดูแลอัตรากำลัง การพัฒนาบุคลากร | ระบบการลาออนไลน์ | https://... |
| ฝ่ายบริหารงานบุคคล | ดูแลอัตรากำลัง การพัฒนาบุคลากร | ระบบประเมินเลื่อนเงินเดือน | https://... |

### แท็บ `ติดต่อ`
เป็นตาราง Key/Value ใส่ได้ 5 แถวตามนี้ (สะกด `Key` ให้ตรงเป๊ะ เป็นตัวพิมพ์เล็กภาษาอังกฤษ)

| Key | Value |
|---|---|
| address | (ที่อยู่โรงเรียน) |
| phone | (เบอร์โทร) |
| email | (อีเมล) |
| facebook | https://www.facebook.com/preedaramschool1 |
| mapEmbedUrl | (ดูวิธีหาในขั้นตอนที่ 5 ด้านล่าง — เว้นว่างไว้ก่อนได้) |

## ขั้นตอนที่ 3 — ติดตั้งสคริปต์เชื่อมต่อ

1. ในสเปรดชีต ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้งทั้งหมด แล้วคัดลอกเนื้อหาทั้งหมดจากไฟล์
   [`apps-script/Code.gs`](../apps-script/Code.gs) ในโปรเจกต์นี้ไปวางแทน
3. กด **บันทึก** (ไอคอนรูปแผ่นดิสก์ หรือ Ctrl+S)

## ขั้นตอนที่ 4 — เผยแพร่เป็น Web App

1. มุมขวาบนของหน้า Apps Script กด **Deploy > New deployment**
2. ช่อง "Select type" กดไอคอนรูปเฟือง เลือก **Web app**
3. ตั้งค่า:
   - **Execute as**: Me (บัญชีของคุณ)
   - **Who has access**: Anyone
4. กด **Deploy** แล้วกด **Authorize access** ยืนยันสิทธิ์ด้วยบัญชี Google เดียวกับที่สร้างชีต
   (ระบบอาจเตือนว่า "Google hasn't verified this app" — เป็นเรื่องปกติเพราะเป็นสคริปต์ของเราเอง
   กด Advanced > ไปที่หน้าชื่อโปรเจกต์ (unsafe) > Allow ได้เลย)
5. จะได้ลิงก์ **Web app URL** หน้าตาประมาณ
   `https://script.google.com/macros/s/XXXXXXXXXXXXXXXX/exec`
   กดคัดลอกลิงก์นี้ไว้

## ขั้นตอนที่ 5 — นำลิงก์ไปใส่ในเว็บไซต์

1. เปิดไฟล์ `index.html` ในโปรเจกต์
2. ค้นหาข้อความ `SHEET_API_URL` (ใช้ Ctrl+F) จะเจอบรรทัดประมาณนี้
   ```js
   var SHEET_API_URL = '';
   ```
3. วางลิงก์ที่คัดลอกมาไว้ระหว่างเครื่องหมายคำพูด เช่น
   ```js
   var SHEET_API_URL = 'https://script.google.com/macros/s/XXXXXXXXXXXXXXXX/exec';
   ```
4. บันทึกและอัปโหลด/commit ไฟล์ขึ้น GitHub ตามปกติ

เท่านี้เว็บไซต์จะดึงข้อมูลจาก Google Sheet มาแสดงแทนข้อมูลตัวอย่าง
**หลังจากนี้แก้ไขข้อมูลแค่พิมพ์ในชีตได้เลย ไม่ต้องแก้ `index.html` หรือ deploy ใหม่อีก**
(ยกเว้นถ้าแก้โค้ดใน `Code.gs` เอง ต้องกด Deploy > Manage deployments > แก้ไข (ไอคอนดินสอ) >
เปลี่ยน Version เป็น "New version" > Deploy ใหม่ ถึงจะมีผล)

### วิธีหา mapEmbedUrl (ใส่แผนที่โรงเรียน) — ไม่บังคับ

1. เปิด [Google Maps](https://maps.google.com) ค้นหาตำแหน่งโรงเรียน
2. กด **แชร์ (Share) > ฝังแผนที่ (Embed a map)**
3. คัดลอกเฉพาะลิงก์ที่อยู่ใน `src="..."` ของโค้ด iframe ที่แสดงขึ้นมา
4. นำลิงก์นั้นไปใส่เป็นค่า `Value` ของแถว `mapEmbedUrl` ในแท็บ `ติดต่อ`

## หมายเหตุ

- ถ้ายังไม่ได้ทำตามคู่มือนี้ หรือ `SHEET_API_URL` ยังว่างอยู่ เว็บไซต์จะแสดงข้อมูลตัวอย่างที่ฝังไว้ในโค้ดไปก่อน
  เว็บจะไม่พังหรือว่างเปล่า
- ถ้าดึงข้อมูลจากชีตไม่สำเร็จ (เช่น ลิงก์ผิด หรืออินเทอร์เน็ตมีปัญหา) เว็บจะสลับกลับไปแสดงข้อมูลตัวอย่างให้อัตโนมัติเช่นกัน
- สเปรดชีตนี้ไม่ต้องแชร์ให้ใครดูก็ได้ (เป็นส่วนตัว) เพราะสคริปต์ทำงานในนามบัญชีของคุณอยู่แล้ว
