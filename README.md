# เว็บไซต์โรงเรียนวัดปรีดาราม (มณีศิริวรรณ)

เว็บไซต์ของโรงเรียน ทำด้วย HTML + CSS + JavaScript ล้วน ไม่ต้องติดตั้งโปรแกรมใด ๆ
แก้ข่าว รายชื่อครู ลิงก์ระบบงาน และข้อมูลติดต่อได้เองผ่านหน้าเว็บ GitHub

ที่อยู่เว็บไซต์: <https://pdrweb-system.github.io/watpreedaram-school/>
(ใช้งานได้หลังเปิด GitHub Pages ตามหัวข้อ [เปิดเว็บไซต์ด้วย GitHub Pages](#เปิดเว็บไซต์ด้วย-github-pages-ทำครั้งเดียว))

## ไฟล์ในโปรเจกต์

## วิธีแก้ข้อมูลผ่านหน้าเว็บ GitHub

1. เปิดไฟล์ `data.js` ในหน้า repo
2. กดรูปดินสอ ✏️ (**Edit this file**) มุมขวาบน
3. แก้ข้อความที่ต้องการ
4. กดปุ่มสีเขียว **Commit changes...** แล้วกด **Commit changes** อีกครั้ง
5. รอประมาณ 1–10 นาที แล้วรีเฟรชหน้าเว็บ (ถ้ายังไม่เปลี่ยน กด `Ctrl` + `F5`)

### กติกาการแก้ไฟล์ data.js

- แก้เฉพาะข้อความที่อยู่ระหว่างเครื่องหมาย `` ` `` (backtick) และอย่าลบเครื่องหมายนี้ออก
- ข้อความข้างในพิมพ์เครื่องหมาย `"` หรือ `'` และขึ้นบรรทัดใหม่ได้ตามปกติ
- แต่ละรายการอยู่ในวงเล็บ `{ }` และคั่นกันด้วยเครื่องหมาย `,`
- **เพิ่มรายการ:** คัดลอกรายการเดิมตั้งแต่ `{` ถึง `},` ไปวาง แล้วแก้ข้อความ
- **ลบรายการ:** ลบตั้งแต่ `{` ถึง `},` ของรายการนั้น
- ช่องที่ไม่ใช้ให้เว้นว่าง เหลือแค่ backtick 2 ตัวติดกัน เช่น `image: ``,`
- บรรทัดที่ขึ้นต้นด้วย `//` เป็นคำอธิบาย ไม่แสดงบนเว็บ

> 💡 บนคีย์บอร์ดที่ตั้งให้ปุ่ม `` ` `` ใช้สลับภาษาไทย/อังกฤษ จะพิมพ์ backtick ไม่ได้
> ให้ใช้วิธีคัดลอกรายการเดิมไปวาง แล้วแก้เฉพาะข้อความข้างใน

## เพิ่มข่าวใหม่

คัดลอกข่าวเดิม 1 รายการ วางไว้ **บนสุด** ต่อจากบรรทัด `news: [` แล้วแก้ข้อความ
หน้าแรกจะแสดง 3 ข่าวแรกเสมอ

```js
  news: [
    {
      tag:   `กิจกรรม`,
      date:  `15 พฤศจิกายน 2569`,
      title: `กีฬาสีภายในโรงเรียน ประจำปี 2569`,
      body:  `นักเรียนทุกระดับชั้นร่วมการแข่งขันกีฬาสีอย่างสนุกสนาน`,
      image: `images/news/sport-day-2569.jpg`,
      link:  `https://www.facebook.com/...`
    },
    ...ข่าวเดิม...
```

- `image` รูปประกอบข่าว (ไม่ใส่ก็ได้) ดูวิธีใส่รูปในหัวข้อถัดไป
- `link` ลิงก์ "อ่านรายละเอียด" (ไม่ใส่ก็ได้) เช่น ลิงก์โพสต์ Facebook หรือไฟล์ PDF ประกาศ

## ใส่รูปภาพ

1. ย่อรูปก่อนอัปโหลด ให้กว้างประมาณ 1200 พิกเซล และไม่เกิน 500 KB
   (รูปจากมือถือมักใหญ่หลาย MB ทำให้เว็บโหลดช้า)
2. ตั้งชื่อไฟล์เป็นภาษาอังกฤษหรือตัวเลข ไม่เว้นวรรค เช่น `sport-day-2569.jpg`
3. ใน GitHub เปิดโฟลเดอร์ `images/news` (รูปข่าว) หรือ `images/staff` (รูปครู)
4. กด **Add file** > **Upload files** > ลากรูปมาวาง > กด **Commit changes**
5. ใน `data.js` ใส่ชื่อไฟล์พร้อมโฟลเดอร์ เช่น

   ```js
   image: `images/news/sport-day-2569.jpg`,
   ```

ชื่อไฟล์ต้องตรงกันทุกตัวอักษร ตัวพิมพ์เล็ก-ใหญ่ก็ต้องตรง (`Photo.JPG` กับ `photo.jpg` ถือเป็นคนละไฟล์)
รูปครูควรเป็นรูปหน้าตรงสัดส่วนจัตุรัส เว็บจะตัดเป็นวงกลมให้เอง

## ผู้อำนวยการและคณะครู

อยู่ในหัวข้อ `director` และ `teachers` ของ `data.js`
ครู 1 ท่านเขียนไว้ใน 1 บรรทัด เรียงตามลำดับที่ต้องการให้แสดงบนเว็บ

```js
    { name: `นางสาวสมศรี ใจดี`, subject: `ครูประจำชั้น ป.1`, photo: `images/staff/somsri.jpg`, initial: `สศ` },
```

`initial` คืออักษรย่อในวงกลม ใช้แสดงเมื่อยังไม่มีรูป (`photo` ว่าง)

## ลิงก์ระบบงานของแต่ละฝ่าย

อยู่ในหัวข้อ `departments` ของ `data.js` ใส่ลิงก์ในช่อง `url` (ขึ้นต้นด้วย `https://`)

- ยังไม่มีลิงก์: ปล่อย `url` ว่าง ปุ่มจะแสดงว่า "(เร็ว ๆ นี้)" และกดไม่ได้
- ไม่ต้องการปุ่ม: ปล่อยว่างทั้ง `linkText` และ `url`

## ข้อมูลติดต่อและแผนที่

ข้อมูลติดต่ออยู่ในหัวข้อ `contact` ของ `data.js`
ถ้าใส่เบอร์โทร (เบอร์เดียว) อีเมล หรือลิงก์ที่ขึ้นต้นด้วย `https://` เว็บจะทำเป็นลิงก์ให้กดได้เอง
อยากเพิ่มช่องทางอื่น เช่น LINE ให้คัดลอกบรรทัดเดิมแล้วแก้ `label` และ `value`

**ใส่แผนที่ Google Maps**

1. เปิด [Google Maps](https://maps.google.com) ค้นหาโรงเรียน แล้วกด **แชร์**
2. เลือกแท็บ **ฝังแผนที่** แล้วกด **คัดลอก HTML**
3. ใน `data.js` วางโค้ดที่คัดลอกมาระหว่างเครื่องหมาย backtick ของ `map` (วางทั้งก้อนได้เลย) เช่น

   ```js
   map: `<iframe src="https://www.google.com/maps/embed?pb=..." width="600" height="450" ...></iframe>`,
   ```

## ซ่อนกล่องหมายเหตุ

กล่องสีครีมใต้เนื้อหาแต่ละหน้าที่บอกว่า "ข้อมูลยังเป็นตัวอย่าง" มีไว้เตือนผู้ดูแลเว็บ
เมื่อใส่ข้อมูลจริงครบแล้ว ให้แก้บรรทัดท้ายไฟล์ `data.js` จาก `showNotes: true` เป็น `showNotes: false`

## แก้วิสัยทัศน์ พันธกิจ อัตลักษณ์ ค่านิยม เอกลักษณ์

ข้อความเหล่านี้อยู่ในไฟล์ `index.html` (หน้า "เกี่ยวกับโรงเรียน")
เปิดแก้ไขแล้วกด `Ctrl` + `F` ค้นหาข้อความเดิม แก้เฉพาะตัวหนังสือ ระวังอย่าลบเครื่องหมาย `<` `>` ที่อยู่รอบข้อความ

## เปิดเว็บไซต์ด้วย GitHub Pages (ทำครั้งเดียว)

1. ในหน้า repo กด **Settings** > เมนูซ้าย **Pages**
2. หัวข้อ **Build and deployment** > **Source** เลือก **Deploy from a branch**
3. **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1–2 นาที เว็บจะอยู่ที่ <https://pdrweb-system.github.io/watpreedaram-school/>

หลังจากนี้ทุกครั้งที่กด Commit changes เว็บจะอัปเดตเอง

## ถ้าหน้าเว็บขึ้นแถบสีแดง

แปลว่า `data.js` มีเครื่องหมายตกหล่น (มักเป็น `,` หรือ backtick) แถบจะบอกเลขบรรทัดที่ควรตรวจ
ส่วนหน้าอื่นของเว็บยังใช้งานได้ตามปกติ

1. เปิด `data.js` กดแก้ไข แล้วไปที่บรรทัดนั้น (เลขบรรทัดอยู่ด้านซ้ายของหน้าแก้ไข)
2. ตรวจบรรทัดนั้นและบรรทัดก่อนหน้า ว่าทุกช่องมี backtick ครบคู่ และท้ายช่องมี `,`
3. ถ้าหาไม่เจอ: เปิด `data.js` กดปุ่ม **History** แล้วคลิกรายการแก้ไขล่าสุด
   จะเห็นแถบสีแดง (ของเดิม) และสีเขียว (ที่แก้ใหม่) ว่าเปลี่ยนตรงไหนไปบ้าง
