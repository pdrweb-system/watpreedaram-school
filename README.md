# เว็บไซต์โรงเรียนวัดปรีดาราม (มณีศิริวรรณ)

เว็บไซต์ของโรงเรียน ทำด้วย HTML + CSS + JavaScript ล้วน ไม่ต้องติดตั้งโปรแกรมใด ๆ
แก้ข่าวได้เองผ่านหน้าเว็บ GitHub ส่วนรายชื่อผู้บริหาร ครู ลิงก์ระบบงาน และข้อมูลติดต่อ
แก้ใน Google Sheet ได้เหมือนแก้ตาราง Excel

ที่อยู่เว็บไซต์: <https://pdrweb-system.github.io/watpreedaram-school/>
(ใช้งานได้หลังเปิด GitHub Pages ตามหัวข้อ [เปิดเว็บไซต์ด้วย GitHub Pages](#เปิดเว็บไซต์ด้วย-github-pages-ทำครั้งเดียว))

## แก้ข้อมูลใน Google Sheet

ผู้บริหาร รายชื่อครู ฝ่ายงาน ข้อมูลติดต่อ และแผนที่ แก้ที่ Google Sheet ของโรงเรียน
พิมพ์แก้ในตารางได้เลย ไม่ต้องเข้า GitHub — รีเฟรชหน้าเว็บก็เห็นข้อมูลล่าสุดทันที

ชีตมี 4 แท็บ ชื่อแท็บและหัวตาราง (แถวที่ 1) ต้องสะกดตรงตามนี้ ส่วนข้อมูลพิมพ์ภาษาไทยได้ตามปกติ
แถวที่ว่างทั้งแถวจะถูกข้ามไป และแท็บไหนว่าง เว็บจะใช้ข้อมูลหัวข้อนั้นจากไฟล์ `data.js` แทน

**แท็บ `ผู้บริหาร`** — 1 แถวต่อ 1 ท่าน ใส่ได้หลายท่าน เช่น รองผู้อำนวยการ

| Initial | Role | Name | Note | Photo |
|---|---|---|---|---|
| ผอ | ผู้อำนวยการโรงเรียน | นายสมชาย ใจดี | ประวัติโดยย่อ (ไม่ใส่ก็ได้) | images/staff/director.jpg |

**แท็บ `กลุ่มสาระ`** — 1 แถวต่อครู 1 ท่าน ครูที่มี `Group` เดียวกันจะอยู่ในแถบเดียวกันบนเว็บ กดที่แถบเพื่อดูรายชื่อ

| Group | Initial | Name | Subject | Photo |
|---|---|---|---|---|
| กลุ่มสาระการเรียนรู้ภาษาไทย | สศ | นางสาวสมศรี ใจดี | ครูประจำชั้น ป.1 | |

**แท็บ `ฝ่ายงาน`** — 1 แถวต่อ 1 ปุ่มระบบงาน ฝ่ายที่มีหลายระบบให้ใส่หลายแถวโดยใช้ `Name` เดียวกัน เว็บจะรวมเป็นการ์ดเดียว
ใส่ `LinkLabel` แต่ยังไม่มี `LinkURL` ปุ่มจะแสดงว่า "(เร็ว ๆ นี้)"

| Name | Description | LinkLabel | LinkURL |
|---|---|---|---|
| ฝ่ายบริหารงานบุคคล | ดูแลอัตรากำลัง การพัฒนาบุคลากร | ระบบการลาออนไลน์ | https://pdrweb-system.github.io/leavesystem/ |
| ฝ่ายบริหารงานบุคคล | | ระบบประเมินตนเองเพื่อใช้ในการเลื่อนเงินเดือน | https://script.google.com/macros/s/... |

**แท็บ `ติดต่อ`** — ตาราง Key / Value เรียงตามลำดับที่ต้องการให้แสดงบนเว็บ

| Key | Value |
|---|---|
| address | ที่อยู่โรงเรียน |
| phone | เบอร์โทร |
| email | อีเมล |
| facebook | https://www.facebook.com/preedaramschool1 |
| mapEmbedUrl | โค้ด "ฝังแผนที่" จาก Google Maps (วิธีคัดลอกอยู่ในหัวข้อ [ข้อมูลติดต่อและแผนที่](#ข้อมูลติดต่อและแผนที่)) |

`Key` อื่นนอกจากนี้จะใช้เป็นหัวข้อบนเว็บตรง ๆ เช่น `LINE` หรือพิมพ์เป็นภาษาไทยก็ได้

**รูปภาพ (`Photo`)** ไม่ใส่ก็ได้ ถ้าจะใส่ ให้อัปโหลดรูปไว้ที่โฟลเดอร์ `images/staff` ใน GitHub ตามหัวข้อ [ใส่รูปภาพ](#ใส่รูปภาพ)
แล้วพิมพ์ชื่อไฟล์พร้อมโฟลเดอร์ เช่น `images/staff/somsri.jpg`
ถ้าใส่แล้วรูปไม่ขึ้น ให้[อัปเดตสคริปต์](#อัปเดตสคริปต์)เป็นเวอร์ชันล่าสุด

## ตั้งค่า Google Sheet (ทำครั้งเดียว)

ลิงก์ชีตของโรงเรียนใส่ไว้ที่ `sheetUrl` ในไฟล์ `data.js` แล้ว ขั้นตอนนี้ใช้เมื่อต้องตั้งค่าใหม่ เช่น ย้ายไปใช้ชีตอื่น

1. สร้าง Google Sheet ใหม่ สร้าง 4 แท็บ ชื่อ `ผู้บริหาร` `กลุ่มสาระ` `ฝ่ายงาน` `ติดต่อ` พร้อมหัวตารางตามหัวข้อด้านบน
2. ในชีต กดเมนู **ส่วนขยาย (Extensions)** > **Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางโค้ดทั้งหมดจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs) กด **บันทึก**
4. กด **Deploy** > **New deployment** > กดไอคอนเฟือง เลือก **Web app** แล้วตั้งค่า
   - **Execute as**: Me
   - **Who has access**: Anyone
5. กด **Deploy** > **Authorize access** แล้วเลือกบัญชี Google เดียวกับที่สร้างชีต
   (ถ้าขึ้นคำเตือน "Google hasn't verified this app" กด **Advanced** > **Go to ... (unsafe)** > **Allow** ได้ เพราะเป็นสคริปต์ของโรงเรียนเอง)
6. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`) ไปวางที่ `sheetUrl` ในไฟล์ `data.js` แล้วกด Commit changes

ไม่ต้องการใช้ Google Sheet: แก้บรรทัด `sheetUrl` ใน `data.js` ให้เหลือ `sheetUrl: ``,` แล้วแก้ข้อมูลทุกหัวข้อในไฟล์ `data.js` แทน

### อัปเดตสคริปต์

เมื่อไฟล์ `apps-script/Code.gs` มีการแก้ไข ให้อัปเดตสคริปต์ในชีตตามนี้ (ลิงก์ `sheetUrl` เดิมใช้ต่อได้ ไม่ต้องเปลี่ยน)

1. เปิดชีต > **ส่วนขยาย** > **Apps Script** วางโค้ดใหม่ทับของเดิมทั้งหมด กด **บันทึก**
2. กด **Deploy** > **Manage deployments** > กดไอคอนดินสอ ✏️ > ช่อง **Version** เลือก **New version** > **Deploy**

## วิธีแก้ข้อมูลผ่านหน้าเว็บ GitHub

1. เปิดไฟล์ `data.js` ในหน้า repo
2. กดรูปดินสอ ✏️ (**Edit this file**) มุมขวาบน
3. แก้ข้อความที่ต้องการ
4. กดปุ่มสีเขียว **Commit changes...** แล้วกด **Commit changes** อีกครั้ง
5. รอประมาณ 1–10 นาที แล้วรีเฟรชหน้าเว็บ (ถ้ายังไม่เปลี่ยน กด `Ctrl` + `F5`)

### กติกาการแก้ไฟล์ data.js

- แก้เฉพาะข้อความที่อยู่ระหว่างเครื่องหมาย `` ` `` (backtick) และอย่าลบเครื่องหมายนี้ออก
- ข้อความข้างในพิมพ์เครื่องหมาย `"` หรือ `'` และขึ้นบรรทัดใหม่ได้ตามปกติ
- แต่ละรายการอยู่ในวงเล็บ `{ }` และคั่นกันด้วยเครื่องหมาย `,`
- **เพิ่มรายการ:** คัดลอกรายการเดิมตั้งแต่ `{` ถึง `},` ไปวาง แล้วแก้ข้อความ
- **ลบรายการ:** ลบตั้งแต่ `{` ถึง `},` ของรายการนั้น
- ช่องที่ไม่ใช้ให้เว้นว่าง เหลือแค่ backtick 2 ตัวติดกัน เช่น `image: ``,`
- บรรทัดที่ขึ้นต้นด้วย `//` เป็นคำอธิบาย ไม่แสดงบนเว็บ

> 💡 บนคีย์บอร์ดที่ตั้งให้ปุ่ม `` ` `` ใช้สลับภาษาไทย/อังกฤษ จะพิมพ์ backtick ไม่ได้
> ให้ใช้วิธีคัดลอกรายการเดิมไปวาง แล้วแก้เฉพาะข้อความข้างใน

## เพิ่มข่าวใหม่

คัดลอกข่าวเดิม 1 รายการ วางไว้ **บนสุด** ต่อจากบรรทัด `news: [` แล้วแก้ข้อความ
หน้าแรกจะแสดง 3 ข่าวแรกเสมอ

```js
  news: [
    {
      tag:   `กิจกรรม`,
      date:  `15 พฤศจิกายน 2569`,
      title: `กีฬาสีภายในโรงเรียน ประจำปี 2569`,
      body:  `นักเรียนทุกระดับชั้นร่วมการแข่งขันกีฬาสีอย่างสนุกสนาน`,
      image: `images/news/sport-day-2569.jpg`,
      link:  `https://www.facebook.com/...`
    },
    ...ข่าวเดิม...
```

- `image` รูปประกอบข่าว (ไม่ใส่ก็ได้) ดูวิธีใส่รูปในหัวข้อถัดไป
- `link` ลิงก์ "อ่านรายละเอียด" (ไม่ใส่ก็ได้) เช่น ลิงก์โพสต์ Facebook หรือไฟล์ PDF ประกาศ

## ใส่รูปภาพ

1. ย่อรูปก่อนอัปโหลด ให้กว้างประมาณ 1200 พิกเซล และไม่เกิน 500 KB
   (รูปจากมือถือมักใหญ่หลาย MB ทำให้เว็บโหลดช้า)
2. ตั้งชื่อไฟล์เป็นภาษาอังกฤษหรือตัวเลข ไม่เว้นวรรค เช่น `sport-day-2569.jpg`
3. ใน GitHub เปิดโฟลเดอร์ `images/news` (รูปข่าว) หรือ `images/staff` (รูปครู)
4. กด **Add file** > **Upload files** > ลากรูปมาวาง > กด **Commit changes**
5. ใน `data.js` ใส่ชื่อไฟล์พร้อมโฟลเดอร์ เช่น

   ```js
   image: `images/news/sport-day-2569.jpg`,
   ```

ชื่อไฟล์ต้องตรงกันทุกตัวอักษร ตัวพิมพ์เล็ก-ใหญ่ก็ต้องตรง (`Photo.JPG` กับ `photo.jpg` ถือเป็นคนละไฟล์)
รูปครูควรเป็นรูปหน้าตรงสัดส่วนจัตุรัส เว็บจะตัดเป็นวงกลมให้เอง

## ผู้อำนวยการและคณะครู

> ใช้ Google Sheet อยู่ (มีลิงก์ที่ `sheetUrl`) ให้แก้ที่แท็บ `ผู้บริหาร` และ `กลุ่มสาระ` ตามหัวข้อ [แก้ข้อมูลใน Google Sheet](#แก้ข้อมูลใน-google-sheet)
> ส่วนนี้ใช้เมื่อไม่ได้ใช้ Google Sheet

อยู่ในหัวข้อ `director` และ `teachers` ของ `data.js`
ครู 1 ท่านเขียนไว้ใน 1 บรรทัด เรียงตามลำดับที่ต้องการให้แสดงบนเว็บ

```js
    { group: `กลุ่มสาระการเรียนรู้ภาษาไทย`, name: `นางสาวสมศรี ใจดี`, subject: `ครูประจำชั้น ป.1`, photo: `images/staff/somsri.jpg`, initial: `สศ` },
```

- `group` คือกลุ่มสาระ ครูที่ใส่กลุ่มเดียวกันจะอยู่ในแถบเดียวกัน (ไม่ต้องการแบ่งกลุ่ม ให้ปล่อยว่างทุกท่าน)
- `initial` คืออักษรย่อในวงกลม ใช้แสดงเมื่อยังไม่มีรูป (`photo` ว่าง)

## ลิงก์ระบบงานของแต่ละฝ่าย

> ใช้ Google Sheet อยู่ ให้แก้ที่แท็บ `ฝ่ายงาน` ตามหัวข้อ [แก้ข้อมูลใน Google Sheet](#แก้ข้อมูลใน-google-sheet)
> ส่วนนี้ใช้เมื่อไม่ได้ใช้ Google Sheet

อยู่ในหัวข้อ `departments` ของ `data.js` ใส่ลิงก์ในช่อง `url` (ขึ้นต้นด้วย `https://`)

- ยังไม่มีลิงก์: ปล่อย `url` ว่าง ปุ่มจะแสดงว่า "(เร็ว ๆ นี้)" และกดไม่ได้
- ไม่ต้องการปุ่ม: ปล่อยว่างทั้ง `linkText` และ `url`
- ฝ่ายที่มีหลายระบบงาน: คัดลอกรายการของฝ่ายนั้นแล้วแก้ `linkText` และ `url` โดยใช้ `name` เดิม เว็บจะรวมเป็นการ์ดเดียว

## ข้อมูลติดต่อและแผนที่

> ใช้ Google Sheet อยู่ ให้แก้ที่แท็บ `ติดต่อ` ตามหัวข้อ [แก้ข้อมูลใน Google Sheet](#แก้ข้อมูลใน-google-sheet)
> (โค้ดแผนที่ใส่ในช่อง `Value` ของแถว `mapEmbedUrl`) ส่วนวิธีคัดลอกโค้ดแผนที่ใช้ได้ทั้งสองแบบ

ข้อมูลติดต่ออยู่ในหัวข้อ `contact` ของ `data.js`
ถ้าใส่เบอร์โทร (เบอร์เดียว) อีเมล หรือลิงก์ที่ขึ้นต้นด้วย `https://` เว็บจะทำเป็นลิงก์ให้กดได้เอง
อยากเพิ่มช่องทางอื่น เช่น LINE ให้คัดลอกบรรทัดเดิมแล้วแก้ `label` และ `value`

**ใส่แผนที่ Google Maps**

1. เปิด [Google Maps](https://maps.google.com) ค้นหาโรงเรียน แล้วกด **แชร์**
2. เลือกแท็บ **ฝังแผนที่** แล้วกด **คัดลอก HTML**
3. ใน `data.js` วางโค้ดที่คัดลอกมาระหว่างเครื่องหมาย backtick ของ `map` (วางทั้งก้อนได้เลย) เช่น

   ```js
   map: `<iframe src="https://www.google.com/maps/embed?pb=..." width="600" height="450" ...></iframe>`,
   ```

## ซ่อนกล่องหมายเหตุ

กล่องสีครีมใต้เนื้อหาแต่ละหน้าที่บอกว่าแก้ข้อมูลได้ที่ไหน และแถบสีเหลืองเมื่อดึงข้อมูลจาก Google Sheet ไม่สำเร็จ มีไว้เตือนผู้ดูแลเว็บ
เมื่อใส่ข้อมูลจริงครบแล้ว ให้แก้บรรทัดท้ายไฟล์ `data.js` จาก `showNotes: true` เป็น `showNotes: false`

## เปิดเว็บไซต์ด้วย GitHub Pages (ทำครั้งเดียว)

1. ในหน้า repo กด **Settings** > เมนูซ้าย **Pages**
2. หัวข้อ **Build and deployment** > **Source** เลือก **Deploy from a branch**
3. **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1–2 นาที เว็บจะอยู่ที่ <https://pdrweb-system.github.io/watpreedaram-school/>

หลังจากนี้ทุกครั้งที่กด Commit changes เว็บจะอัปเดตเอง

## ถ้าหน้าเว็บขึ้นแถบสีแดง

แปลว่า `data.js` มีเครื่องหมายตกหล่น (มักเป็น `,` หรือ backtick) แถบจะบอกเลขบรรทัดที่ควรตรวจ
ส่วนหน้าอื่นของเว็บยังใช้งานได้ตามปกติ

1. เปิด `data.js` กดแก้ไข แล้วไปที่บรรทัดนั้น (เลขบรรทัดอยู่ด้านซ้ายของหน้าแก้ไข)
2. ตรวจบรรทัดนั้นและบรรทัดก่อนหน้า ว่าทุกช่องมี backtick ครบคู่ และท้ายช่องมี `,`
3. ถ้าหาไม่เจอ: เปิด `data.js` กดปุ่ม **History** แล้วคลิกรายการแก้ไขล่าสุด
   จะเห็นแถบสีแดง (ของเดิม) และสีเขียว (ที่แก้ใหม่) ว่าเปลี่ยนตรงไหนไปบ้าง

## ถ้าหน้าเว็บขึ้นแถบสีเหลือง

แปลว่าดึงข้อมูลจาก Google Sheet ไม่สำเร็จ หน้าบุคลากร ฝ่ายงาน และติดต่อเรา จึงแสดงข้อมูลสำรองจาก `data.js` แทน
แถบจะบอกสาเหตุไว้ ที่พบบ่อยคือ

- ลิงก์ `sheetUrl` ใน `data.js` คัดลอกมาไม่ครบ หรือไม่ได้ลงท้ายด้วย `/exec`
- ตอน Deploy ไม่ได้ตั้ง **Who has access** เป็น **Anyone**
- ชื่อแท็บหรือหัวตารางในชีตสะกดไม่ตรง (เช่น มีเว้นวรรคเกิน)

แถบนี้เห็นเฉพาะตอน `showNotes: true` ผู้เข้าชมเว็บจะไม่เห็นเมื่อเปลี่ยนเป็น `showNotes: false`
