# รูปประกอบข่าว

อัปโหลดรูปประกอบข่าวไว้ในโฟลเดอร์นี้ (กด **Add file** > **Upload files**)

- ย่อรูปให้กว้างประมาณ 1200 พิกเซล และไม่เกิน 500 KB
- ตั้งชื่อไฟล์เป็นภาษาอังกฤษหรือตัวเลข ไม่เว้นวรรค เช่น `sport-day-2569.jpg`
- จากนั้นใส่ชื่อไฟล์ในช่อง `image` ของข่าวในไฟล์ `data.js` เช่น `` image: `images/news/sport-day-2569.jpg`, ``
