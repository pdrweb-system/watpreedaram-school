# รูปผู้อำนวยการและครู

อัปโหลดรูปถ่ายผู้อำนวยการและครูไว้ในโฟลเดอร์นี้ (กด **Add file** > **Upload files**)

- ใช้รูปหน้าตรง สัดส่วนจัตุรัส กว้างประมาณ 400 พิกเซล เว็บจะตัดเป็นวงกลมให้เอง
- ตั้งชื่อไฟล์เป็นภาษาอังกฤษหรือตัวเลข ไม่เว้นวรรค เช่น `director.jpg`, `teacher-01.jpg`
- จากนั้นใส่ชื่อไฟล์ในช่อง `photo` ในไฟล์ `data.js` เช่น `` photo: `images/staff/director.jpg`, ``
